Answer re-encoding
CP ≠ CA

Answer query 形成另一套可解码、可用于输出的 count representation。

本组实验分别回答三个问题：(i) 同一 role 的 counter geometry 是否跨层连续；(ii) answer query hidden state 是否能在未见 seed 上预测 gold count；(iii) 定向 patch 或移除这些 component 是否改变生成结果。

目前结论：证据支持“同一 role 内逐层传播、到 answer role 后重新编码”的宏观结构；它不是一个从 prompt 到 answer 始终固定不变的 residual subspace。

2 · Counter subspace 的定义与跨层比较

对每个模型、role、layer，先按 count 1–10 求 centroid μc，再对中心化后的 10 个 centroid 做 SVD。前三个右奇异向量组成 Uℓ∈Rd×3。它们解释的 centroid variance 中位数为：Qwen prompt 98.2%、answer 96.1%；Gemma prompt 95.9%、answer 97.8%。

两个 rank-3 subspace 的 overlap 定义为：

Overlap(U,V)=‖UᵀV‖²F/3 ∈ [0,1].

2.1 · 补充验证：是否存在被跨层保留的抽象 count state

为什么只看 subspace overlap 还不够。Overlap 检查两个 residual-space span 是否使用相同轴；如果网络把同一 count geometry 旋转到另一组轴，它会下降，却不代表 count 关系消失。为此补做两个只读分析，均直接使用冻结的 packed states，不重跑生成。

3 · Answer hidden state 能否预测 count

在每一层的 answer-query hidden state 上做 10 类分类。每个 fold 内依次执行标准化、PCA 到最多 32 维，再训练分类器；PCA 与分类器都只在训练 folds 内拟合。五折 GroupKFold 以 seed 为组，因此同一 seed 不会同时出现在训练与测试中。

固定分类器原则。逐层选六个算法中的最大值会产生 layer-wise model-selection bias，因此不再把 algorithm envelope 当主结果。我们先冻结选择准则为“两模型 × all/correct × 全部层共 156 个 layer-dataset 的平均 seed-held-out accuracy”，据此选定 nearest centroid：全局平均 accuracy 0.478，高于 L2 logistic 0.475；在机制相关晚层窗口的平均 accuracy 为 0.733，也高于 logistic 的 0.689。它只比较测试点到训练 fold 各 count centroid 的距离，和本文的 geometry 问题直接一致。该算法选择是在本 campaign 汇总后作出，属于 post-hoc 方法冻结；后续独立确认应预注册 nearest centroid，不再重新选算法。

4 · Causal test：patch、matched control 与 removal

实验单位。使用 10 个全新 confirmation seeds（1254–1263）。每个 seed 构造五对相邻 count (1,2)…(9,10)，并双向交换 receiver/donor，共每模型 100 jobs。两个模型合计 200 jobs；每个 job 生成四个条件，因此共有 800 条 intervention outcomes。

冻结位置。Qwen source=L28 最后一个 needle endpoint，answer mediator=L29 answer query；Gemma source=L36，mediator=L37。所有 rank-3 basis 均只用 discovery data 拟合。

Source projected patch

δP=UPUPᵀ(hdonor−hreceiver)

只把 donor−receiver 差异在 prompt counter subspace 内的投影，加到 receiver 的最后 needle endpoint。

Norm-matched orthogonal control

δ⊥ ⟂ UP, ‖δ⊥‖=‖δP‖

随机方向与 prompt basis 正交，并严格匹配 residual delta norm。

Answer removal

h′=h−UAUAᵀ(h−h̄)

在下一层 answer query 完全移除 centered rank-3 answer counter component（dose=1）。

Patch + removal

先做 source projected patch，再在因果改变后的 forward 中执行 answer removal，用于 serial mediation 检验。

预注册主指标是 normalized donor-aligned shift：

D=sign(cd−cr)·(ŷcondition−ŷclean)/|cd−cr|.

正值表示输出朝 donor count 移动。补充报告 removal 对 receiver gold 的绝对误差增量 H=|ŷrem−cr|−|ŷclean−cr|。统计均先在 seed 内平均，再对 10 个 seed 做 10,000 次 cluster bootstrap CI 与精确 one-sided sign-flip test。

目前结论：Answer-query rank-3 component 具有强 causal relevance：移除后两模型误差都显著上升，且多数原本正确的输出被破坏。但 source projected patch 完全没有推动 donor adoption，因此本实验没有建立“最后 needle endpoint rank-3 state → answer state”的充分性或 serial mediation。
严格边界：Answer removal 尚缺同一 answer-query 位置、相同 intervention norm 的 orthogonal-removal control，所以应写成强 necessity-like evidence，而不是已经排除一切非特异扰动。Patch+removal 与 removal-only 几乎相同，是因为 patch 本身为零效应；不能把它包装成成功 mediation。

晚层稳定传播

同一 role 的相邻层 overlap 在晚层升到约 .76–.86。

→
Answer 重新编码并读取

Prompt/answer axes 近正交；answer state 可高精度分类，移除 answer component 会显著伤害输出。

  • Representation：不是单一固定 counter vector 穿过所有层与位置，而是 role-specific low-dimensional manifolds。
  • Readout：Answer query 内的 count code 是成功回答所使用的表征之一。
  • 尚未定位的桥：当前 source patch 只作用于最后 needle endpoint 的 rank-3 centroid subspace；真正的桥可能是 distributed span、多维非-centroid carrier、attention/MLP relay，或发生在更早层/其他 token。
目前结论：A 组完成了“跨层连续性 → answer 可读性 → answer causal relevance”三段证据；尚缺的是从 prompt carrier 到 answer code 的选择性路径干预。论文中应把这条边画成待定位的 transformation，而不是已证明的单箭头。
