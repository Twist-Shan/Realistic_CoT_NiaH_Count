1 · 两层 parser：先选“轨迹”，再定“token”

这两层 parser 解决的是不同问题。第一层回答“哪条 native-thinking 轨迹足够干净，可以进入因果实验”；第二层回答“在这条轨迹内，第 k 次引用究竟从哪个字符与 token 开始，干预应该落在哪一个真实 token”。把二者合并会把 cohort selection 与 causal localization 混为一谈。

1.1 第一层：strict one-to-one cohort parser

底层 city-list parser 先从完整 thinking trace 中抽取 accepted city sequence。若观测多重集与 gold 多重集严格相等，则 trace_one_to_one=True：

one_to_one ⇔ len(observed)=len(gold) ∧ Counter(casefold(observed))=Counter(casefold(gold))

因此它要求每个 gold city 恰好出现一次且没有额外城市；但不要求 passage-order。正序、严格逆序与其他置换都会分别记录，并都可进入 one-to-one cohort。parser_hit、one_to_one 与 final answer correct 是三个不同变量；targeted-retrieval confirmation 进一步采用 one_to_one_correct，以便把“干预造成的正确→错误”解释为损伤。

重要边界：该 parser 使用注册的 gold cities 对 trace item 做对齐，是一个实验 alignment instrument，而不是无需 gold information 的部署时 blind parser。

1.2 第二层：response-reference 与 token-position parser

对每个 occurrence k，Qwen 与 Gemma 各有 deterministic response parser。若 item 内存在 canonical copied-record prefix In the 2024 city score audit，citation 从该 prefix 的首字符开始；否则从 exact cited city 的首字符开始。然后用模型自身 tokenizer 的 offset mapping 找到重叠 citation 的首 token，query 固定为它左侧一个真实 baseline token：

qₖ = token immediately before citation_start(k);   distance(qₖ, citation_first_token)=1

这里不使用 marker 后、前句结尾、pre_city_d2 或 anchor。第 k 个 response citation 按 city identity 唯一匹配 prompt 中的 exact needle span R(cₖ)。如果 raw output 不能无损重 tokenize 成 baseline prefix、citation 没有左侧 token，或 prompt 中同 city 的 exact span 不唯一，就排除并审计，不做 fallback。

2 · k-to-k targeted retrieval：定义与确认性结果

2.1 Head score

在 discovery-only attention 上，对每个 head 同时报告目标 needle 的绝对 attention mass 与在所有 active prompt needles 中的相对占比：

raw_mass(h,k) = Σⱼ∈R(cₖ) Aₕ(qₖ,j)
relative_mass(h,k) = raw_mass(h,k) / Σᵢ Σⱼ∈R(cᵢ) Aₕ(qₖ,j)

主排序用 raw mass；relative mass 只作诊断。三种回答类型先在各类型内求均值，再等权平均成同一个跨回答类型 consensus bank；不会为不同回答类型挑不同的主 bank。冻结 K∈{1,2,4,8,16,32} 的 ranked bank 后，在 confirmation 上与三组 disjoint exact layer-matched random controls 比较。

3 · “Qwen 未显著”到底指什么？

准确写法：在 parser-defined pre_reference_d1、跨回答类型 consensus bank、actual-greedy next-citation endpoint 的预注册 confirmation 主检验中，Qwen 各 K 的 ranked-vs-random specificity 均未通过跨模型 Holm 校正。

它不表示以下内容：Qwen 没有检索；Qwen 的 attention map 不看 exact needle；Qwen 的 answer state 不携带 count；或 Qwen 的所有 causal tests 都不显著。事实上，Qwen answer hidden-state full donor adoption 为 91.7%，说明最终 answer state 明确可执行。

3.1 K=8 是“提示性”，不是“确认性”

K=8 的 pooled all-accuracy specificity 为 0.9%，bootstrap CI [0.3%, 1.5%]，未校正 sign-flip p=0.016；但预注册 family 的 Holm p=0.141。因此，若事后只看 K=8 会得到“有小效应”的印象，但在所有 K 与双模型共同控制 family-wise error 后，证据不足以称为确认性显著。

3.2 更关键的是效应形状

Qwen 的效应没有剂量单调性：K=8 是正的，但 K=16 回落为 -0.4%，K=32 仅 0.7%。这与 Gemma K=8→16→32 的 21.9%→33.6%→86.9% 形成鲜明对比。Qwen 的问题不只是 12 个 seed clusters 带来的 power 较低，更是效应本身只有约一个百分点且不稳定。

可检验解释 A · 冗余/分布式检索

Qwen 可能由多条 heads、residual 或 MLP 路径共同携带 city identity；按 raw mass 排出的少数 heads 有“看向 needle”的描述性特征，却不是唯一必要 carrier。

可检验解释 B · query 已经太晚

在 citation 首 token 前一位置，Qwen 可能已经把将要引用的城市写入 residual state。此时消融当前 token 的 top attention heads 只能造成很小损伤。

可检验解释 C · mass 与 OV 写入不一致

高 attention mass 只说明读取权重高，不保证 value/output projection 沿有用方向写入。应以 OV/path attribution 或 output-norm-weighted score 复核。

可检验解释 D · parser 类型不平衡

Qwen occurrence 以 bare/list 为主（968/1445），semantic cue 较少（91/1445）。主统计已在 seed 内等权类型，但稀有类型仍提供较少独立信息。

这些是机制假设，不是当前数据已证明的原因。最直接的验证是：保持同一 confirmation registry，比较 raw-mass、relative-mass、OV-norm、path patching 四种 discovery bank，并测试更早的 pre-reference window；不能在 confirmation 上重新选最显著位置。

4 · 为什么 aggregation 全部不显著？

V3 broad aggregation 完全复用了 non-thinking 的 primary score，并把 prompt spans 与 trace item spans 分开排序：

broad_primary(h) = total_mass(h) × exp(H(per_span_mass(h))) / span_count

随后运行 clean、prompt-only、trace-only 与 joint 四条件；K={1,2,4,8,16,32}，joint 还报告在 exact-control constructability 下的最大并集（Qwen 58、Gemma 61）。72 个 actual-greedy final-count 主检验中 0 个显著，最小 Holm p=0.748。

4.1 首要事实：ranked ablation 根本没有改变一个最终数字

Qwen 的 88 个 clean-correct request 与 Gemma 的 53 个 clean-correct request 中，所有 prompt-only、trace-only、joint、所有 K 的 ranked prediction changed = 0。也就是说，null 不是单纯“有损伤但统计 power 不足”，而是被该 operational intervention 选中的 heads 对严格 greedy numeric answer 表现出完全的行为鲁棒性。

4.2 最合理的机制解释

① 聚合可能已在更早位置完成

干预点是第一个数字答案 token 前一 token。长 thinking trace 结束时，count 可能早已写入 residual state；答案 query 只执行稳定读出。

② Attention coverage 不是因果贡献

mass × effective coverage 选的是“广泛读取多个 spans”的 head，不衡量 value 内容、OV 输出方向或 downstream path gain。高分 head 可能只做格式、复制或无效读取。

③ 多头与 MLP 存在冗余

单 token、有限 head bank 的 output-slice zeroing 可能被其他 heads、residual stream 或 MLP 重构。joint 最大 bank 仍不改 ranked final answer，支持“不是窄瓶颈”。

④ Endpoint 很严格但较粗

实际 final numeric count 是正确主 endpoint，却对置信度、候选 margin 或 trace wording 的变化不敏感。这里不能用 logit 指标替代行为结论，只能说未改变最终数字。

⑤ Cohort 有意偏向稳定轨迹

one-to-one 且 clean-correct 的样本能提供清楚的 correct→wrong endpoint，但也属于更稳定、更易恢复的轨迹，可能降低局部 ablation 的敏感性。

⑥ 对照校正排除了 generic damage

主效应是 ranked 减 exact layer-matched random。即使大规模删 head 造成一般退化，只要 ranked 不比同层 random 更坏，就不能归因于 broad aggregation 机制。

可以与不可以推出什么可以推出：按 non-thinking broad score 排出的 prompt/trace answer-query heads，在本次单点 output-slice zeroing 与严格最终计数 endpoint 下，不是独占、可检出的因果瓶颈。不能推出：Native Thinking 不做 aggregation。聚合仍可能在 trace 内更早发生、存在 residual/MLP 中，或由大量冗余 heads 分布式实现。

4.3 与 answer-state patch 的联合解释

这是最关键的组合证据：broad head ablation 为 null，但 full hidden-state donor adoption 在 Qwen/Gemma 分别为 91.7%/98.0%。因此，最终 count state 存在且可执行；当前 broad ranking 没有定位到写入这个 state 的唯一 heads。这比笼统写“aggregation 不存在”更符合数据。
