Clean-correct patching 强化 hidden-state 结论；head ablation 给出待冻结确认的模型/总体特异候选

1. 结论摘要

Hidden state：受限功能主张已充分

Answer-query clean-correct patching 的 donor-target accuracy 为 Qwen 96.6%、Gemma 96.0%。

receiver 与 donor 的 clean 输出均正确，替换后仍高概率输出 donor 的 gold count；因此结果不再依赖“运输 donor 的错误预测”这一替代解释。它支持“answer-query hidden state 保存下游可用的 donor-associated 正确计数信息”，但不证明显式整数编码或唯一回路。

Head bank：有功能信号，尚未冻结确认

n=1–5 内的候选为 Qwen 全样本 n=2、correct-only n=4；Gemma 两类均 n=1。

这些候选来自同一批 fresh seeds 上的 n 扫描，故是 fresh-seed discovery candidate。Qwen 两类总体的最佳 n 不同，说明不能强行给 Qwen 一个“统一最佳 n”；Gemma correct-only n=1 的 CI 下界恰为 0，也必须保留不确定性。

2. 实验问题与设定

2.1 原 causal-v2

模型为 Qwen3-8B 与 Gemma4-E4B；计数范围 0–10，干预距离 k∈{1,3,5}。九个无向 count pairs 为 k=1 的 (0,1)/(4,5)/(9,10)，k=3 的 (0,3)/(3,6)/(7,10)，k=5 的 (0,5)/(2,7)/(5,10)，每对运行双方向。原正式实验使用 centroid seeds 1234–1253、screen seeds 1254–1258、held-out confirmation seeds 1259–1263；prompt/answer patching 与 steering 均在 screen 后冻结 condition 再确认。

本节结论 · 数据支持

原实验提供了独立 screen/confirmation 和配对控制，是定位可干预表示的正式证据；其 patching 未要求 receiver/donor clean 都答对。

2.2 clean-correct patching 扩展

eligible pair 要求同一 seed 下 receiver 与 donor 的 clean generation 都精确等于各自 gold count。保留原 screen 选择出的 patching condition，只对 eligible pairs 汇总；每个模型×k×方向目标为 5 个 seed clusters。若原 confirmation 不足，则按固定 reserve-seed 顺序扫描并在满足预定配额时停止。

2.3 两类 ablation

两类分析共享同一批 counts 1–5、seeds 1274–1283 和同一组干预输出：全样本总体保留 clean 对错全部样本；correct-only 总体是其中 clean prediction 正确的精确子集。每个 n 有 ranked broad-aggregation bank 与至少 3 组 layer-matched random controls。主分析只比较 n=1–5；n=6–32 已保存为额外诊断，但不参与本报告候选判定。

本节结论 · 数据支持

全样本与 correct-only 使用相同计数域、seed 前缀和干预实现，因此差异主要来自分析总体，而不是不同运行条件。

3. 概念、指标与统计计算

3.1 Clean-correct average patching accuracy

对每个 patch pair-condition 实例 i，receiver gold 为 rᵢ、donor gold 为 dᵢ、patched numeric output 为 yᵢ。定义：

PatchAcc = (1/N) Σᵢ 𝟙[patched output 有效 且 yᵢ = dᵢ].

无效输出留在分母并计 0。表中 k×方向点估计按 pair-condition instance 加权；95% CI 对 seed clusters 做 10,000 次 bootstrap。报告中的 pooled 值是六个 k×方向组 successes/denominator 的描述性比率，不附加一个未经定义的 pooled CI；图中的误差条是各组 cluster bootstrap CI。另报 post-patch receiver accuracy，以区分“仍保留 receiver 答案”与“运输 donor 答案”。

本节结论 · 数据支持

PatchAcc=1 表示所有有效/无效都按严格分母计算后完全命中 donor gold；它比方向运输更直接，但仍是所测 patch sites/conditions 的充分性指标，不是必要性指标。

3.2 全样本 ablation：大小与方向

clean prediction 为 y₀，ranked bank 消融后为 y⁽ᴿ⁾ₙ，第 j 个随机 bank 后为 y⁽ʲ⁾ₙ。主量为：

Dabs(n) = E|y⁽ᴿ⁾ₙ−y₀| − (1/J)ΣⱼE|y⁽ʲ⁾ₙ−y₀|,   J≥3.

Dabs>0 表示 ranked bank 相对随机造成更大的计数变化。方向量另报 Dsigned(n)=E[y⁽ᴿ⁾ₙ−y₀]−meanⱼE[y⁽ʲ⁾ₙ−y₀]；负值偏向降低计数，正值偏向提高计数。主量不把正负抵消，方向量用于解释变化方向。

本节结论 · 数据支持

全样本指标回答“消融是否改变输出以及朝哪个方向”，不要求 clean 答案原本正确。

3.3 Correct-only ablation：破坏正确答案

只在 y₀=g 的样本上定义 correct→wrong。主量为：

Dcw(n) = P(y⁽ᴿ⁾ₙ≠g | y₀=g) − (1/J)ΣⱼP(y⁽ʲ⁾ₙ≠g | y₀=g).

Dcw>0 表示 ranked heads 被消融后，比随机 heads 更常把正确答案破坏成错误答案。分母分别是 Qwen 40、Gemma 36 个 clean-correct stimuli；效应先按 seed cluster 聚合，再做 10,000 次 cluster bootstrap。CI 下界严格大于 0 才记为 excludes-zero；恰好等于 0 不算。

本节结论 · 数据支持

Correct-only 指标最直接对应“这些 heads 对维持正确计数是否有用”；它不评价原本错误样本能否被消融纠正。

9.1 候选 n 的含义

Qwen 全样本最大 D_abs 在 n=2：0.133 [0.013, 0.300]；correct-only 最大 D_cw 在 n=4：0.083 [0.023, 0.158]。Gemma 两类都在 n=1 最大：全样本 0.147 [0.060, 0.233]，correct-only 0.102 [0.000, 0.205]。Gemma correct-only 下界恰为 0，故不能说 CI 严格排除零。

本节结论 · 数据支持

允许模型/总体特异 n 后，当前最自然候选是 Qwen 2/4、Gemma 1/1；不存在数据支持的统一 Qwen n。它们是候选，不是冻结结果。

9.2 非单调性与 random overlap

n 增大时效应不单调，意味着不能声称 head 排名可加、删得越多一定越坏，也不能从曲线反推“真实 head 数量”。但 ablation 只需证明某个预先指定 bank 的干预比控制更有影响，单调性不是必要条件。Qwen correct-only n=4 的 random controls 平均与 ranked bank 重叠 1 个 head；在其他条件相同且共享 head 只会共同移除信号的理想情形下，这通常会衰减 contrast，但它并不自动保证“更保守”，因为控制集合与方差结构也被改变。Qwen 全样本 n=2、Gemma n=1 的 overlap 为 0，解释更干净。

本节结论 · 数据支持

Overlap 不抹去观测到的差异，却降低“ranked 与随机是互斥处理”的解释纯度；下一次冻结确认应禁止 overlap。

10. 单模型与跨模型整合

共同点：两个模型的 answer-query clean-correct patching 都约 96%，说明 donor gold 信息在最终 query state 上具有高度可执行性；两个模型在全样本 ablation 的最佳 n 都有 CI 严格大于 0，说明 ranked heads 的行为效应不是只出现在一个模型。差异：Qwen prompt patching 更异质且 pooled 较低；Gemma prompt 总体更高但 k=5 increase 明显较弱。Ablation 上 Gemma 用 n=1 即达到两类总体最大效应，而 Qwen 全样本与 correct-only 分别偏向 n=2 与 n=4。

这些差异不能解释为“模型能力排名”：模型层数、head 结构、tokenizer remap、clean-correct 子样本量与原 baseline 错误分布均不同。跨模型的一致性支持较抽象的功能主张；具体 n 必须模型/总体特异。

本节结论 · 数据支持

跨模型一致的是“answer-query hidden state 可运输正确 donor count，且 ranked-head ablation 可比随机更具破坏性”；不一致的是最佳 bank 大小与部分 prompt 条件强度。

11. 这些实验是否足够，以及还需补什么

11.1 已经足够的主张

  • Answer-query hidden state 含下游可用的正确计数信息：足够。clean-correct receiver/donor、严格 donor-gold endpoint、两模型、双方向和 seed-cluster CI 共同支撑。
  • Ranked heads 会影响计数行为：作为 discovery-level 功能证据足够。全样本与 correct-only 分开后都出现 ranked-minus-random 正效应。
  • 唯一计数回路、精确 head 数量、单调剂量反应：没有证明，也不是当前目标。
本节结论 · 数据支持

按受限论文叙述，patching 与 ablation 已经能支持“state 有信息、heads 有功能信号”；措辞需保留 discovery/confirmation 区分。

11.2 若要写成“可重复的特定 head-bank 贡献”

  1. 在任何新结果可见前冻结四个模型×总体候选：Qwen 全样本 n=2、Qwen correct-only n=4、Gemma 全样本 n=1、Gemma correct-only n=1；不再重新选择 n。
  2. 使用完全未参与本次扫描的新 seed suffix，计数仍固定 1–5；每模型至少 10、建议 20 个 seed clusters。
  3. 每个 candidate 使用至少 3 组 layer-matched random controls，并强制与对应 ranked bank 零重叠。
  4. 全样本 primary endpoint 固定 D_abs，correct-only 固定 D_cw；每个模型×总体只做一个冻结检验，并对四个 primary tests 做 Holm correction。报告 seed-level effects、cluster bootstrap CI、exact sign-flip p 与 valid rate。

这一步不需要重跑 n=1–5，更不需要 n=6–32；它只确认当前候选。若文章只采用 correct-only 功能主张，则可以只确认 Qwen n=4 与 Gemma n=1，并把全样本作为已完成的描述性补充。

本节结论 · 最小补充

最低补实验是 frozen-n、new-seed、zero-overlap confirmation；不是再次扫描 n。确认前，报告必须称“candidate/functionally sensitive heads”，不能称“已确认的固定 head bank”。
