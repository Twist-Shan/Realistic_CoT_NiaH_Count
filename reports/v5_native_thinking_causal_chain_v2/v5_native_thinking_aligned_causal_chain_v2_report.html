5. 解释边界

  • 显著的 targeted-retrieval ablation 支持这些 heads 对局部下一-needle 生成具有必要性；它不单独证明最终 count 由同一 head bank直接执行。
  • Answer 四条件区分 prompt-sequence aggregation、thinking-trace aggregation及其 joint union；主要行为指标是解析后的实际输出 count。
  • Marker patch 检验 hidden state 是否携带可交换的 needle 信息；answer patch 检验 count state 的 transport/adoption。两者 endpoint 不可互换。
  • 每一统计结论应以 effect、CI 与跨模型 Holm p 联合解释；“流水线完成”不等于“所有机制效应显著”。
