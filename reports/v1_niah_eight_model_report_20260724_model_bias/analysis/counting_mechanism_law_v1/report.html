1. 机制假说与定义

令 L 为目标 haystack token 长度，N 为 needle 数。基础坐标为 l=log(L/5000) 与 n=log(N/5)。所有 exact correctness 都把解析失败、未按格式和截断保留为失败；数值误差只在成功解析的输出上定义并明确报告分母。

Failure-hazard / survival law
pm(L,N,o)=exp(−exp(am+rmln(L5000)+smln(N5)+om1{query-last}))p_m(L,N,o)=\exp\{-\exp[a_m+r_m\ln(L/5000)+s_m\ln(N/5)+o_m\mathbb{1}_{\mathrm{query-last}}]\}
Logistic / Hill law
logit(pm(L,N,o))=am+rmln(L5000)+smln(N5)+om1{query-last}\operatorname{logit}p_m(L,N,o)=a_m+r_m\ln(L/5000)+s_m\ln(N/5)+o_m\mathbb{1}_{\mathrm{query-last}}
Enumeration retrieval compounding
logit(qm(L,N,o))=am+rmln(L5000)+smln(N5)+om1{query-last}\operatorname{logit}q_m(L,N,o)=a_m+r_m\ln(L/5000)+s_m\ln(N/5)+o_m\mathbb{1}_{\mathrm{query-last}}
P(all N gold pairs found)≈qm(L,N,o)NP(\mathrm{all\ }N\mathrm{\ gold\ pairs\ found})\approx q_m(L,N,o)^N

这里的 q 是逐 needle 的 pair-recall 概率：每条枚举输出以 N−missing_pairs 为成功数、N 为试验数。q^N 是“各 needle 检索近似独立”时全部找齐的复合概率，因此它比只回归最终准确率更接近可检验的 counting/retrieval mechanism。

7. 结论边界

  • “统一 law”在这里指统一的函数族，不是统一参数；每个模型都允许不同的 a、r、s 和 query-order nuisance 参数。
  • 三种 mode 分开选择，避免把 nonthinking、enumeration 与 CoT 的不同失败机制压成一个斜率。
  • pair retrieval、parse、truncation 与 numeric count 是统计关联的机制指标，不构成神经网络内部因果机制的直接证明。
  • 实验只覆盖 L∈{2000,5000,10000}、N∈{1,2,3,4,5,6,8,10,20,30}；任何区间外外推都需要新实验验证。

8. 第二阶段：从相关检索与正负误差混合中提炼机制

第一阶段的两个失败诊断被保留：独立 needle 假说 q^N 对 all-pairs-found 的 held-out cell R² 较低；单一 signed-bias 曲面也因欠计与多计抵消而不稳定。第二阶段在看到这些失败后单独冻结，只比较 N_eff=κN^τ 与 under/over hurdle 两个有机制含义的小型候选族。

8.5 第二阶段的解释边界

  • Stage 2 是由预先保留的 failure diagnostics 触发的探索性细化；它与 stage-1 预注册比较分开记录。
  • 高 cell R² 说明响应面在当前 L、N 网格内可复现，不意味着能外推到更长 context 或更大的 N。
  • N_eff 是相关性/异质性的经验摘要；hurdle law 是输出行为分解。二者都不是对隐藏状态内部算法的直接因果识别。
