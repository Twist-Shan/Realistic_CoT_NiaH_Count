核心结论。 准确率不能只用 needle density N/T 概括：分开的长度项与 needle 数量项明显优于 density-only。最简洁且验证表现最好的统一形式是每个模型具有不同参数的 Hill/power law；needle 阶在八个模型上均为正且更稳定，长度阶因为只有 3 个长度水平而不如 needle 阶精确。
  • Counting mechanism：枚举模式的逐 needle 检索不符合独立复合 qN。held-out 数据支持 Neff,m(N)=κmNτ， 其中共享 τ=0.747（seed-cluster bootstrap 95% CI 0.641–0.850）； blocked-cell R2=0.758，而独立基线只有 0.326。
  • Bias：正负 bias 需要分成 over/under 概率与条件误差量级。 该 hurdle 分解在 enumeration 与 CoT 上把 held-out cell R2 提高到 0.311 与 0.288； direct 的 signed bias 不支持同一分解，因此不把它包装成统一定律。
  • 模型表现：Qwen3-32B 总体最高（76.2%），其后为 Gemma4-E4B（69.9%）和 Qwen3-8B（68.0%）。
  • thinking：对支持原生 thinking 的 Qwen/Gemma，native-thinking 模式相对 direct 均提高准确率；但同时改变了解码预算/温度，因此应解释为“完整模式差异”，不能单独归因为隐藏推理开关。
  • 主要回归：共享斜率模型中，长度翻倍的 odds ratio 为 0.711，needle 数翻倍为 0.544；两者的 stimulus-cluster bootstrap 95% CI 均不跨 0。
  • 错误机制：Gemma4-12B 的 direct 模式主要被 97.7% 截断拖累；Llama3.2-3B 的 enumeration 模式既大量无法解析，也出现极端多计。枚举模式的平均绝对误差常被少数巨大 over-count 主导，因此报告同时给出中位数和 signed-bias 稳健统计。

实验设定与统计口径

注册网格

  • Haystack 长度 T：2,000、5,000、10,000 个 canonical passage tokens。
  • Needle 数量 N：1、2、3、4、5、6、8、10、20、30。
  • Seed：1234–1238，共 5 个；因此有 3×10×5=150 个 master stimuli。
  • Query order：任务在 passage 前（query_first）或后（query_last）。
  • 模型：Qwen3 三种规模、Gemma4 两种、OLMo-Hybrid-7B、Llama3.1-8B、Llama3.2-3B。

提示与 thinking

  • direct：thinking 关闭，只要求最终一行 Total: <integer>；max tokens=64，temperature=0。
  • enumeration：thinking 关闭，要求逐条列出 city-score record 再给 Total；max tokens=1,536，temperature=0。
  • native_thinking：与 direct 使用相同任务文字，但 chat template 打开原生 thinking；max tokens=4,096。Qwen temperature=0.6，Gemma temperature=1.0。
  • Llama/OLMo 不支持本实验定义下的 native thinking，因此每个模型为 600 请求；Qwen/Gemma 各 900 请求。

错误情况与原因

互斥一级分类

  1. 截断：生成达到长度限制或被标记 truncated；即便出现部分列表，只要没有正确最终结果仍计失败。
  2. 格式/解析失败：非截断，但冻结 parser 没有抽取到规定的最终整数，通常是缺少 Total:、输出额外格式或生成了无法解析的文本。
  3. 少计/多计：成功解析整数，但分别小于/大于真实 N。
  4. 正确：解析出的 Total 与真实 N 完全一致。
为什么平均绝对误差会很大：多个 enumeration 模式虽然大多数请求正确或误差很小，但少数输出把无关编号/重复内容当成计数并产生数百乃至更大的 Total。于是均值被长尾支配，而中位数仍可能为 0。报告不会删除这些点，因为它们是真实模型失败。

枚举模式的可观测机制标签

冻结 evaluator 对 enumeration 输出还能检测 gold pair 是否遗漏、是否出现幻觉 pair、是否重复列出 pair，以及列表长度是否与 Total 一致。下表只统计 enumeration 中的错误请求；后四列是可重叠的机制标签，因此不能相加当作总数。

Empirical law：猜想、验证与拟合

候选猜想

  1. Density-only：logit(p) 只依赖 log(N/T)。这是最强的“由密度完全决定”假设。
  2. 分离的 log T 与 log N：logit(p)=控制项+bTlog₂(T/5000)+bNlog₂(N/5)。它允许 passage 长度和 needle 数量有不同阶。
  3. 带交互的 response surface：在上一式加入 log T × log N，检验一个维度的效应是否随另一个维度改变。
  4. 统一形式、每模型不同参数：八个模型共享同一 Hill/power 函数族，但 A、长度阶 r 和 needle 阶 s 各不相同。
  5. 原始坐标 exponential 与其他 link：作为有边界的替代函数族，与 power/Hill 一起用 held-out 数据比较。

绝对误差与 signed bias

条件绝对误差 law

绝对误差只在 5,385/6,300（85.5%）条成功解析输出上拟合。选中的 log/power 坐标写为：

Conditional absolute-error law
zi=ln(1+|bi|)z_i=\ln(1+|b_i|)
E[zi|parsed, m, T, N, q, o]≈ln(Bm)+umln(T5000)+vmln(N5)+ηq+κo\mathbb E[z_i\mid\mathrm{parsed},m,T,N,q,o]\approx\ln B_m+u_m\ln(T/5000)+v_m\ln(N/5)+\eta_q+\kappa_o
Bm 是拟合的 baseline 误差尺度；um、vm 是乘法阶数。T 翻倍使拟合的 geometric-scale (1+|b|) 乘以 2uₘ，N 翻倍使其乘以 2vₘ。该 law 只描述已成功解析数值时的典型误差量级。

Signed bias

原始平均 bias 是字面上的统计偏差，但被少数巨大正向异常值严重拉高。总体 parsed-output mean bias 为 35.08，中位数为 0.00。因此报告同时给出原始均值、10% trimmed mean、中位数、[-30,30] capped bias 与 asinh(bias)；bias-law v4 用 500 次 stimulus-cluster bootstrap，并对八个模型的检验做 Holm 调整。

结论：可以得到 bias 作为纵坐标的结果，但不存在一个对所有模型都稳定的统一 signed-bias 方向。典型输出的中位 bias 多接近 0；部分模型/枚举模式出现少数巨大多计，使 raw mean 显著为正。因而 bias law 更适合作为错误机制诊断，而不是替代准确率 law。

每个模型各自的 bias empirical law

这一节把八个模型完全拆开拟合；任何模型都不借用其他模型的斜率或截距。样本仍限于成功解析出数值的 5,385 条输出，未解析、格式失败和截断继续在 primary accuracy 中计为失败，并且不会被伪造为 bias=0。

目标与可解释的固定形式

Robust signed-bias target
bi=N^i−Ni,zi=arsinh(bi)=ln(bi+bi2+1)b_i=\widehat N_i-N_i,\quad z_i=\operatorname{arsinh}(b_i)=\ln(b_i+\sqrt{b_i^2+1})
cm(T,N,q,o)=sinh(E[zi|parsed, m, T, N, q, o])c_m(T,N,q,o)=\sinh\{\mathbb E[z_i\mid\mathrm{parsed},m,T,N,q,o]\}
cm 称为 asinh-centered bias，回到 count 单位并保留正负方向。asinh 在 0 附近近似线性、在长尾处近似对数，所以少数巨大 over-count 不会像 raw mean 那样支配拟合；cm 既不是 raw mean，也不是 median。
用于跨模型比较的固定函数族
E[zi|parsed, m, T, N, q, o]=αm,q,o+βm,Tlog₂(T5000)+βm,Nlog₂(N5)\mathbb E[z_i\mid\mathrm{parsed},m,T,N,q,o]=\alpha_{m,q,o}+\beta_{m,T}\log_2(T/5000)+\beta_{m,N}\log_2(N/5)
βm,T 是 T 翻倍时 mean asinh(bias) 的变化，βm,N 是 N 翻倍时的变化；它们是 transformed-response units，不是原始计数的直接增量。正值表示更趋向 over-count，负值表示更趋向 under-count。每个模型的最终选式仍由 grouped held-out 验证决定。

每个模型还独立比较 condition-only、density-only、分离 log T/log N、带交互 log surface、以及原始归一化 T/N。最终坐标使用留一 seed、留一 N、留一 T 与 blocked cell 四套验证；另做外层留一 seed、内层重新选坐标的 nested 验证，避免只报告挑选后的训练拟合。

Qwen 三个参数量：能共享什么，不能共享什么

Qwen 家族：共享函数形式与共享参数是两个不同假设
E[arsinh(bi)|m,q,o,L,N] =αm,q,o +βLlog2(L5000) +βNlog2(N5) \mathbb E[\operatorname{arsinh}(b_i)\mid m,q,o,L,N]=\alpha_{m,q,o}+\beta_L\log_2(L/5000)+\beta_N\log_2(N/5)
E[arsinh(bi)|…] =αm,q,o +βm,Llog2(L5000) +βm,Nlog2(N5) \mathbb E[\operatorname{arsinh}(b_i)\mid\cdots]=\alpha_{m,q,o}+\beta_{m,L}\log_2(L/5000)+\beta_{m,N}\log_2(N/5)
第一式要求 Qwen 三个参数量共享 L/N 斜率；第二式只共享函数族，让每个规模拥有自己的斜率。两者都保留 model × prompt mode × query order 截距，并用相同 grouped held-out splits 比较。

最好的共享斜率候选是 Shared log density：四类 grouped split 平均 asinh-bias MAE 为 1.123，相对 condition-only（1.104）改善 -1.7%，在 0/4 类切分中胜出。它没有达到共享斜率 law 的预设支持门槛；因此只能说 Qwen 可以共用候选函数族，不能把同一组 L/N 参数当成已发现的家族定律。

允许模型特异斜率后，最佳候选为 Model-specific raw L + N，相对最佳共享式再改善 +0.2%。固定 log 坐标下，长度斜率有 2/3 个模型显著为正、0/3 显著为负；needle 斜率有 1/3 显著为正、1/3 显著为负。尤其 N 的方向在 Qwen3-1.7B 与 Qwen3-32B 之间相反，所以不能用单一 needle-count 阶数概括三个规模。

解释边界与限制

  • 长度水平只有 3 个：虽然 needle 有 10 个水平，T 只有 2k/5k/10k；因此“长度是幂律还是其他平滑函数”的辨识力有限，任何 10k 以外外推都不可靠。
  • 模式没有完全交叉：Llama/OLMo 没有 native-thinking 条件；模型 family、tokenizer、architecture 与 thinking availability 也没有正交化。
  • thinking 比较含解码差异：native-thinking 同时更改 max tokens、temperature、top-p/top-k。观察差值是整个推理模式的关联，非 isolated causal effect。
  • 误差量级是条件结果：absolute error 和 signed bias 只在 parsed outputs 上定义；模型若经常不产出可解析答案，条件误差看起来可能很小，却不代表总体性能好。
  • 均值被长尾支配：极端 over-count 是有效失败，不能删掉；但报告 raw mean 时必须并列中位数、trimmed/capped/asinh 稳健版本。
  • 预测而非因果：所有 law 都是注册网格内的 empirical response surface，不能推断模型内部因果机制。

7. 结论边界

  • “统一 law”在这里指统一的函数族，不是统一参数；每个模型都允许不同的 a、r、s 和 query-order nuisance 参数。
  • 三种 mode 分开选择，避免把 nonthinking、enumeration 与 CoT 的不同失败机制压成一个斜率。
  • pair retrieval、parse、truncation 与 numeric count 是统计关联的机制指标，不构成神经网络内部因果机制的直接证明。
  • 实验只覆盖 L∈{2000,5000,10000}、N∈{1,2,3,4,5,6,8,10,20,30}；任何区间外外推都需要新实验验证。
